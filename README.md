# Claude Hub Widget

Desktop-Widget für KDE Plasma 6: zeigt Token-Verbrauch, Abo-Limits und laufende Sessions von
[Claude Code](https://claude.com/claude-code) im Glas-Look. Ein Klick öffnet Claude Hub.

Die Zahlen kommen von [Claude Hub](https://github.com/Fynn7909/claude-hub)
(`claude-hub --widget-json`), die App muss also installiert sein.

## Installieren

    git clone https://github.com/Fynn7909/claude-hub.git
    (cd claude-hub && ./install.sh)

    git clone https://github.com/Fynn7909/claude-hub-widget.git
    cd claude-hub-widget
    ./install.sh

Danach Rechtsklick auf den Desktop > „Miniprogramme hinzufügen“ > „Claude Hub“.

Entfernen: `./install.sh --uninstall`.
